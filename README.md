> **受够了主流社交软件的臃肿与监控？欢迎来到恩信（Gracelink），一个把隐私权和社交自由还给用户的避风港。**

## 💡 为什么发起这个项目？

在“数据裸奔”的时代，我们几乎找不到一个可以安心说话的地方。主流 App 充满了广告投喂、算法监控和无尽的权限索取。作为一名“爱折腾技术的留学生”，我决定打破这种现状，开发一套真正纯净、安全、全功能的社交平替系统。

**恩信（Gracelink）的底线：**
- **无监控**：消息端到端逻辑防护，不设云端审查。
- **无广告**：朋友圈就是朋友圈，拒绝算法投喂和微商刷屏。
- **无权限滥用**：不强制读取通讯录，不关联实名信息。

---

## ✨ 核心特性

### 1. 深度私密聊天 (Private Chat)
- 极致轻量化架构，消息即时触发。
- 物理级销毁机制，让沟通只留在当事人的设备上。

### 2. 纯净好友圈 (Circle)
- 拒绝权重过滤和广告插入。
- 只有你关注的好友动态，找回最初朋友圈的感动。

### 3. 去中心化媒体号 (Media Channel)
- 创作者的自由净土。
- 内容直达订阅者，无算法干预，让信息回归内容本身。

### 4. 高效“传音” (Broadcast)
- 独家自研的信息触达机制。
- 比群发更精准，比普通消息更具穿透力，满足高频社交需求。
